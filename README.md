# Сергей Кияницын — QA portfolio

Персональный сайт-портфолио QA-инженера: опыт работы, кейсы, контакты и PDF-резюме. Создан на React, TypeScript и Vite.

## Структура

```text
src/
  app/          композиция страницы
  components/   общие компоненты
  sections/     разделы сайта
  data/         профиль, опыт работы и кейсы
  assets/       фотография и PDF-резюме
  styles/       общие стили
  main.tsx      точка входа
index.html      HTML-шаблон
start.ps1       локальный запуск в Windows
```

## Локальный запуск

Windows, Node.js 22.12+. Скрипт установит зависимости, если они отсутствуют, и запустит сайт; адрес появится в терминале.

```powershell
.\start.ps1
```
